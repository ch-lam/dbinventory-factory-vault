# Dbinventory factory notes

The long-term memory of the Dbinventory factory's agents: decisions, pitfalls and methods
that the code and `git log` do not hold. The rules are in [`CLAUDE.md`](CLAUDE.md).

- **Who writes:** the agent holding the Timon role `librarian`, through the `doc` task Timon
  opens after each merge. Humans may write too, by the same rules.
- **Where the agents see it:** in `vault/` of the shared workspace clone
  (`~timon/workspaces/<repository>/vault/`), cloned by the team kit and excluded from the
  workspace repository.
- **Reading it:** clone this repository and open it as an Obsidian vault, or browse it in GitLab.

Seeded once by the Factory Seed; Git owns it. The agents push to `main` directly: no
pipeline, no merge request.
